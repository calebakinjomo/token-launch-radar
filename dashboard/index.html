How the number is made

Implied value = TVL × category multiple × growth × maturity. The multiple is the median market-cap-per-$1-TVL of live-token protocols in the same category (at least two of them, each holding $10M+ of TVL); a category with fewer falls back to the global median. Growth is the seven-day TVL change at half weight. Maturity is how long the protocol has run with no token. Every figure comes from the sealed snapshot — no name on this board is hardcoded, and the value is this radar's own claim, never a prediction that a token will launch.
